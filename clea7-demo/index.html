ASISTENT.
TI ODLUČUJEŠ.

AI može predložiti strukturu aplikacije i objasniti projekt. Prijedlog se provjerava i primjenjuje tek kada ga prihvatiš. Model može pogriješiti.

Windows lokalni CPU model

Za računare bez WebGPU možeš povezati lokalni llama-server. Model se ne šalje vanjskom AI servisu; njegovo instaliranje je zaseban korak.

Model u pregledniku

Qwen2.5 0.5B uz WebLLM. Zahtijeva WebGPU i preuzimanje velikih modelskih datoteka. Na starijem laptopu možda neće raditi; osnovni Studio ne zahtijeva AI.

Model nije učitan. Nema automatskog preuzimanja.

Odgovor se prikazuje samo nakon stvarnog izvršavanja modela.

Prva aplikacija

  1. Kreiraj projekt iz stvarnog predloška.
  2. Promijeni naziv, ekrane i polja.
  3. Sačuvaj, pa pokreni aplikaciju.
  4. Dodaj zapis, uredi ga i provjeri pretragu.
  5. Preuzmi HTML i JSON kopiju; otvori HTML iz foldera.

HTML radi samostalno s ugrađenim CLEA7 runtimeom. Podaci su odvojeni po pregledniku i domeni. JSON kopija služi za prenos i oporavak.

SDK za web aplikacije

const runtime = new CLEA7.Runtime();
const result = await runtime.run(
  'moja-aplikacija', 'table.stats',
  {rows: [{iznos: 15}, {iznos: 25}]},
  {dependencies: {schema: 1}}
);

Operacije: text.transform, data.filter, table.stats. Ulazi, verzije, zavisnosti i prostor aplikacije ulaze u identitet cachea. Nema izvršavanja proizvoljnog koda iz projekta.

Privatnost i granice

Projektni podaci ostaju lokalno. Nema analitike, računa, plaćenih API-ja ili automatskog slanja sadržaja. AI datoteke preuzimaju se samo nakon pristanka. AI koristi resurse.

Web Worker odvaja posao od interfejsa, ali nije potpuna sigurnosna granica za nepouzdan kod. Nema potvrđenog per-worker RAM ograničenja, tvrdnje o nultoj energiji ili garantovane novosti.

Originalnost i licence

Studio, projektni format i koordinacioni kod napisani su za ovaj projekt. Korištenje standardnih browser i Windows funkcija nije kopiranje izvornog koda tih sistema.

Opcioni AI koristi WebLLM (Apache-2.0) i Qwen2.5 0.5B (Apache-2.0); to nisu naši modeli. Potrebne obavijesti prate distribuciju. Naziv CLEA7 još nije pravno odobren.

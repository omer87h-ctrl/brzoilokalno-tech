# Grad majstora — acceptance record

This checklist is paired with executable verification, not a claim that merely
rendering the interface establishes completion.

- `scripts/test_grad_core.cjs`: closed schema; real build costs/rejection;
  traversable routes and closure rerouting; deterministic isolated forecast;
  actual labor/power/capacity constraints; stock-based objectives; safe save/import;
  upgrades/salvage/hiring; full 35-contract, seven-project completion.
- `scripts/test_grad_browser.cjs`: real canvas selection and construction;
  first district complete through UI; forecast/cancel/commit; undo; all tabs;
  actual backup and image downloads; corrupt and valid import; restart;
  voluntary LinkedIn URL; stale-tab write rejection; 390/360 layout; reduced
  motion; serious/critical WCAG scan; storage failure; offline restart; PNG card.
- Deployment preserves pinned TECH source, runs existing portal/workspace/export
  checks and compares actual published game bytes and social image to the build.

Local pure-rule suite: 10 groups passed, with all 35 contracts reached in 24
game days by a scripted strategy using legal commands. This is not a human playtime
measurement. Real Chrome and public publication results are in the corresponding
GitHub Actions run logs and `grad-evidence/` artifacts, once executed.

Physical-device battery/memory/performance, all browsers and native packages are
not established by Chrome viewport tests. No such claims appear in the game.
The game is original standalone web code, not a completed CLEA7 game-renderer adapter.
